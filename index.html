Manual rápido

Procedimiento básico para el uso diario de la plataforma de Turno de Abogados.

Guía operativa
Objetivo de la plataforma: apoyar la búsqueda, revisión, registro y seguimiento de abogados de turno. Cada funcionario debe ingresar con su usuario, revisar cuidadosamente la información antes de guardar y mantener actualizados los datos de contacto.

1. Ingreso a la aplicación

  1. Escribe tu RUT funcionario en el campo de ingreso. Puedes digitarlo con o sin puntos; la aplicación lo formateará automáticamente.
  2. Ingresa tu clave asignada y presiona Ingresar.
  3. Al entrar, revisa el panel lateral izquierdo. Debe aparecer tu nombre como Usuario conectado.
  4. Todas las acciones importantes que realices quedarán asociadas a tu usuario para efectos de trazabilidad.
  5. Cuando termines de trabajar, presiona Cerrar sesión.

2. Sincronizar datos

  1. Presiona Sincronizar datos al iniciar el trabajo en la aplicación.
  2. Usa también este botón después de guardar un cambio, incorporar un abogado, registrar un turno o subir un documento.
  3. La sincronización actualiza la búsqueda, la ficha de abogados, el ranking, las alertas, los abogados nuevos, los turnos mensuales y la biblioteca de decretos.
  4. Espera el mensaje de confirmación antes de continuar con otra tarea.
  5. Si no ves un dato recién ingresado, vuelve a sincronizar y revisa nuevamente la sección correspondiente.

3. Buscar abogado

  1. En el menú izquierdo, selecciona Buscar abogado.
  2. Escribe el nombre, apellido o parte del nombre del abogado. La búsqueda muestra coincidencias disponibles en la base.
  3. Si necesitas acotar resultados, usa los filtros de materia, meses sin turno y habilitación.
  4. Selecciona una tarjeta de resultado para abrir la Ficha del abogado.
  5. En la ficha revisa RUT, domicilio, teléfono, correo, materias históricas, tribunales, total de turnos y detalle de turnos realizados.
  6. Si detectas datos desactualizados, presiona Editar contacto, corrige la información y guarda.

4. Habilitar o deshabilitar para turno

  1. En la ficha del abogado, ubica el selector Habilitado para turno.
  2. Selecciona Sí cuando el abogado pueda ser considerado en futuros turnos.
  3. Selecciona No cuando exista una razón que impida considerarlo en el ranking.
  4. Al marcar No, debes elegir una causal o escribir una justificación breve. La razón es obligatoria.
  5. El documento de respaldo es opcional. Cuando exista, puedes adjuntarlo y quedará disponible desde la ficha.
  6. Un abogado no habilitado no aparecerá como candidato en el ranking de nuevo turno.

5. Registrar abogados nuevos

  1. Usa la sección Abogados nuevos cuando el abogado aún no tenga turnos históricos registrados.
  2. Completa RUT, nombre completo, correo, teléfono, domicilio, estado de habilitación y observaciones si corresponde.
  3. El RUT es obligatorio para registrar abogados nuevos.
  4. Antes de guardar, revisa que el nombre esté escrito correctamente y que los datos de contacto sean utilizables.
  5. El abogado nuevo quedará disponible para búsqueda y ranking sin crear un turno histórico.
  6. Cuando ese abogado realice su primer turno, pasará a formar parte de los registros históricos de turnos.

6. Generar y registrar nuevo turno

  1. Ingresa a Nuevo turno.
  2. Revisa el ranking sugerido. Los abogados nuevos sin turno realizado aparecen priorizados y los no habilitados quedan excluidos.
  3. Usa los filtros de materia, tribunal y meses sin turno para revisar candidatos según la necesidad del turno.
  4. También puedes usar el buscador rápido para ubicar un abogado habilitado dentro del ranking.
  5. Presiona Usar este abogado para llevar sus datos al formulario de registro.
  6. Verifica o cambia materia, tribunal, mes, estado y observaciones antes de guardar.
  7. Lee la ventana de confirmación y guarda solo si la información está correcta.

7. Gestionar excusas y reemplazos

  1. Ingresa a Excusas y reemplazos cuando un abogado designado no realizará el turno.
  2. Selecciona el mes del turno y busca por nombre, materia o tribunal.
  3. Elige el turno original que será marcado como excusado.
  4. Registra el motivo de excusa, el número de D.E. y una observación clara.
  5. Después de marcar la excusa, el sistema prepara el formulario para registrar al abogado reemplazante.
  6. Selecciona o ingresa el reemplazante, revisa materia, tribunal, mes y estado, y guarda el registro.
  7. El abogado excusado no cuenta como turno realizado; el reemplazante queda registrado como realizado por reemplazo.

8. Revisar turnos mensuales

  1. Ingresa a Turnos de Abogados para revisar el turno mensual conformado.
  2. Selecciona el año y el mes que deseas consultar.
  3. La tabla muestra materia, tribunal, abogado, D.E., datos de contacto, estado y observaciones.
  4. Revisa los colores y estados para distinguir originales vigentes, originales reemplazados y reemplazantes vigentes.
  5. Esta sección sirve para confirmar rápidamente quién integra un turno mensual y con qué datos de contacto.

9. Decretos Económicos

  1. Ingresa a Decretos Económicos para consultar documentos de respaldo disponibles.
  2. Filtra por año o busca por número de D.E. o parte del nombre del archivo.
  3. Presiona Ver documento para abrir el PDF correspondiente.
  4. Para cargar un decreto nuevo, presiona Ingresar nuevo decreto económico.
  5. Completa año, mes, número de D.E. y adjunta el PDF.
  6. Después de subirlo, sincroniza o actualiza la biblioteca para confirmar que quedó disponible.

10. Alertas e historial

  1. Usa Alertas de información para revisar datos incompletos, como abogados sin correo, teléfono, domicilio o RUT.
  2. Los campos pendientes se destacan visualmente para facilitar su corrección.
  3. Desde esa sección puedes completar datos faltantes y guardar los cambios.
  4. El Registro de cambios permite revisar quién modificó información, cuándo lo hizo y qué dato cambió.
  5. El historial está restringido a jefatura. Si no tienes autorización, verás el mensaje Acceso solo para jefatura.
